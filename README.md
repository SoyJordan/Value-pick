- Eliminadas las métricas de temporada del motor.
- Últimos 5 en casa para el local y últimos 5 fuera para el visitante.
- Días de descanso: una sola casilla por equipo.
- Campos vacíos no cuentan como 0; el peso se redistribuye entre las ventanas disponibles.
- Fuente de datos opcional por análisis.
- Hándicap asiático ±1 con Win / Push / Loss y EV correcto.
- Robustez recalibrada para considerar el peor EV y la sensibilidad a ±7% en lambda.
- Mantiene historial, backups, borrador automático, edición y eliminación individual.
