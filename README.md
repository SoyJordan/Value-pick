# Value Pick V1.4

PWA local/manual para análisis de fútbol.

## V1.4
- Sistema de ausencias por jugador.
- Estado: baja confirmada / duda / disponible.
- Importancia ofensiva y defensiva 0–100.
- Multiplicador automático: confirmada 100%, duda 50%, disponible 0%.
- Impactos ofensivo y defensivo limitados a 0–100 por equipo.
- Ajuste del lambda de Poisson por ausencias.
- Historial local, liquidación, PnL/ROI y backup JSON.
- Sin APIs y sin servidor de datos.

## Publicación
El repositorio puede publicarse con GitHub Pages desde `main` / raíz. GitHub Pages requiere un `index.html` en el nivel superior de la fuente publicada.
