# SoyJordan Picks V1.6.1

## Motor
- Conserva sin cambios el motor V1.6: Últimos 10 = 50%, Últimos 5 = 30%, Últimos 5 condición = 20%.
- Mantiene Poisson, EV, robustez, ausencias, descanso y hándicap asiático ±1.

## Gestión de apuestas
- Registro de apuestas reales desde cualquier pick guardado en el historial.
- Monto apostado, cuota realmente tomada, unidades opcionales.
- Estados: Pendiente, Ganada, Perdida y Nula/Push.
- P&L, porcentaje de acierto y ROI de apuestas individuales.

## Combinadas
- Construcción de combinadas a partir de picks de análisis guardados.
- Cuota combinada y retorno potencial automáticos.
- Liquidación por pierna: WIN / LOSS / PUSH.
- Una pierna PUSH pasa a cuota 1.00 en la liquidación.

## Cajero / Bank
- Panel visible con Bank inicial, Bank actual, dinero en juego y disponible.
- Bank inicial editable.
- Ingresos/retiros manuales.
- Bank actual se actualiza con el P&L realizado de apuestas y combinadas.

## Backup
- Backup V1.6.1 guarda análisis, apuestas, combinadas y bank.
- Importación compatible con backups antiguos que contienen solo análisis.
